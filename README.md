# Portfolio SISR - Administration d’Infrastructures Sécurisées

## Présentation

Ce portfolio présente ma progression vers les métiers des systèmes, réseaux et de la cybersécurité défensive.

Objectif : démontrer des bases techniques proches d’un niveau Bac+2 informatique en construction, avec une orientation vers l’administration d’infrastructures sécurisées.

## Objectif professionnel

Je recherche une alternance en support informatique, systèmes et réseaux, administration junior ou sécurité opérationnelle afin de progresser sur des missions terrain :

- support utilisateurs ;
- préparation et déploiement de postes ;
- gestion de parc informatique ;
- diagnostic réseau ;
- administration Windows/Linux ;
- documentation technique ;
- sécurité de premier niveau ;
- supervision ;
- automatisation simple.

## Compétences travaillées

- Windows et Linux / Ubuntu ;
- bases réseau : IP, DNS, DHCP, LAN, Wi-Fi ;
- diagnostic de connectivité ;
- support utilisateur niveau 1 / niveau 2 ;
- documentation technique ;
- cybersécurité défensive ;
- scripts Bash et PowerShell ;
- notions Active Directory, GPO, virtualisation, supervision ;
- sensibilisation RGPD, phishing, mots de passe et sauvegardes.

## Progression technique

| Mois | Travaux réalisés |
|---|---|
| Mai 2026 | Création du portfolio SISR, scripts Bash/PowerShell simples, fiche diagnostic réseau local, fiche sécurité poste utilisateur |
| Juin 2026 | Préparation d’un lab Windows Server / Active Directory, sécurisation d’un serveur Linux, documentation d’un homelab virtualisé |
| Juillet 2026 | Mise en place prévue d’un lab de supervision avec Zabbix ou Grafana, documentation d’incidents N1/N2 |
